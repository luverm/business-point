# Business Point verkoopregistratie

Webpagina waarop het salesteam van Business Point Roosendaal offertes, boekingen en campagnes invult, met een KPI-dashboard dat realisatie tegen de doelen zet. Gemaakt door LMG strategie+creatie.

- De hele pagina staat in `index.html`; er is geen bouwstap.
- Gegevens worden opgeslagen via een Make-koppeling. De pagina bevat geen wachtwoorden of toegangscodes: die worden in Make gecontroleerd.
- Wijzigen: pas `index.html` aan en push naar `main`. GitHub Pages zet de nieuwe versie binnen een minuut online.
